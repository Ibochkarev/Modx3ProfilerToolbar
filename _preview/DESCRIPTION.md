# Modx3ProfilerToolbar — тулбар производительности для MODX 3

Лёгкий профайлер только с **Frontend Dev Toolbar**: метрики запроса, медленные компоненты, таймлайн и SQL. Без админки, без хранения трейсов.

**Версия:** 1.0.0-pl

## Ключевые возможности

- **Frontend Dev Toolbar** — панель в правом нижнем углу: время, память, сниппеты, SQL; по клику — вкладки Overview, Slow Components, Timeline, SQL. Локализация (ru/en/uk).
- **MODX Pipeline** — учёт событий MODX (OnHandleRequest, OnLoadWebDocument, OnWebPagePrerender), сниппеты, чанки, плагины, SQL.
- **Advisor** — подсказки по оптимизации: некэшированные сниппеты, N+1, медленные запросы, перегруз чанков.
- **Production-safe** — sampling 1–100%, тулбар только при входе в Manager; накладные расходы < 5%.

## Как это работает

1. Включите профайлер в настройках (namespace **modx3profilertoolbar**) и при необходимости — frontend toolbar.
2. Откройте любую страницу сайта (контекст web). При входе в Manager в правом нижнем углу появится Dev Toolbar с метриками текущего запроса.
3. Разверните панель — вкладки Overview, Slow Components, Timeline, SQL покажут, где ушло время и какие компоненты самые тяжёлые.

Изменений в шаблонах не требуется. Трейсы нигде не сохраняются.

## Требования

| Компонент | Версия |
|-----------|--------|
| MODX Revolution | 3.x |
| PHP | 8.1+ |

VueTools и админка не требуются.

## Установка

1. Установите пакет через **Пакеты → Установщик** (или загрузите transport из репозитория).
2. В **Управление → Системные настройки** (фильтр **modx3profilertoolbar**) включите **modx3profilertoolbar.enabled** и **modx3profilertoolbar.frontend_toolbar**.
3. Откройте страницу сайта, будучи залогиненным в Manager — в углу появится тулбар.

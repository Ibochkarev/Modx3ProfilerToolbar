# Превью для ModStore и соцсетей

Материалы для публикации дополнения **Modx3ProfilerToolbar** (Performance Toolbar для MODX 3) на [modstore.pro](https://modstore.pro) и для превью в GitHub/соцсетях.

**Версия:** 1.0.0-pl  
**Статус:** Только Frontend Dev Toolbar, без админки и хранения трейсов.

## Файлы

| Файл | Назначение |
|------|------------|
| **DESCRIPTION.md** | Описание возможностей и сценариев — для ModStore |
| **logo-256.png** | 256×256 px — иконка для карточки ModStore, аватар репозитория |
| **banner-1200x630.png** | 1200×630 px — баннер страницы пакета, Open Graph |

## Использование

- **ModStore:** загрузите логотип и баннер в карточку пакета; текст из DESCRIPTION.md.
- **GitHub:** logo-256.png — изображение репозитория; banner — og:image.
- Папка `_preview/` не входит в транспортный пакет — только для репозитория и ModStore.

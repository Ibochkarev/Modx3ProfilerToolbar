# Modx3ProfilerToolbar — тулбар производительности для MODX 3

Лёгкий профайлер только с **Frontend Dev Toolbar**: метрики запроса, медленные компоненты, таймлайн и SQL. Без админки, без хранения трейсов, без debug-отчёта.

**Версия:** 1.0.0-pl

## Обзор

### Зачем нужен

Быстро видеть по каждому запросу: общее время, TTFB, PHP/SQL, память, количество сниппетов и SQL, топ медленных компонентов и рекомендации (Advisor). Всё в компактной панели в правом нижнем углу страницы — только для пользователей, залогиненных в Manager.

### Ключевые возможности

- **Frontend Dev Toolbar** — панель в углу страницы: время, память, сниппеты, SQL; по клику — вкладки Overview, Slow Components, Timeline, SQL. Локализация (ru/en/uk).
- **MODX Pipeline** — учёт событий MODX (OnHandleRequest, OnLoadWebDocument, OnWebPagePrerender), сниппеты, чанки, плагины, SQL.
- **Advisor** — подсказки по оптимизации: некэшированные сниппеты, N+1, медленные запросы, перегруз чанков.
- **Production-safe** — sampling (1–100%), тулбар только при входе в Manager; накладные расходы < 5%.

### Ограничения

**pdoTools 3.x:** Fenom-сниппеты и pdoTools-сниппеты (msProducts, pdoResources и т.д.) в MODX 3 **не профилируются** автоматически. См. документацию.

**Что работает:** события MODX, SQL, память, общее время, стандартные теги `[[!Snippet]]` (частично).

## Быстрый старт

1. **Установка** — установите через **Пакеты → Установщик**. Админка и VueTools не требуются.
2. **Настройка** — **Управление → Системные настройки**, фильтр **modx3profilertoolbar**. Включите **modx3profilertoolbar.enabled** и **modx3profilertoolbar.frontend_toolbar**.
3. **Проверка** — откройте любую страницу сайта, будучи залогиненным в Manager. В правом нижнем углу появится Dev Toolbar.

## Требования

- PHP 8.1+
- MODX Revolution 3.x

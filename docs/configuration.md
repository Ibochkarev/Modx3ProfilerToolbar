# Настройка Modx3ProfilerToolbar

Системные настройки открываются через **Управление → Системные настройки**, фильтр по namespace **modx3profilertoolbar**. Ниже описаны все параметры пакета.

## Основные параметры

### modx3profilertoolbar.enabled

- **Описание:** Включить или выключить профилирование запросов.
- **Тип:** Да/Нет (combo-boolean).
- **По умолчанию:** Нет.
- **Рекомендация:** Включите на dev/staging; на production — при необходимости, лучше вместе с sampling.

### modx3profilertoolbar.sampling_rate

- **Описание:** Процент запросов, которые профилируются (1–100).
- **Тип:** Число.
- **По умолчанию:** 100.
- **Рекомендация:**
  - **Разработка:** 100 (все запросы).
  - **Production:** 1–5 (1–5% запросов для снижения нагрузки).

### modx3profilertoolbar.frontend_toolbar

- **Описание:** Показывать ли панель Dev Toolbar на фронтенде (контекст web).
- **Тип:** Да/Нет.
- **По умолчанию:** Да.
- **Рекомендация:** Включайте только для разработчиков; на production лучше выключить. Тулбар показывается только при входе в Manager.

## Безопасность

Профайлер выводит чувствительные данные: SQL-запросы, имена сниппетов и плагинов.

- Тулбар показывается только пользователям, залогиненным в Manager. Ограничьте доступ к админке.
- На production используйте sampling 1–5%.

## Пороги и метрики

### modx3profilertoolbar.slow_query_ms

- **Описание:** Порог (в миллисекундах), выше которого SQL-запрос считается медленным и помечается в Advisor.
- **По умолчанию:** 100.

### modx3profilertoolbar.slow_snippet_ms

- **Описание:** Порог (в миллисекундах) для пометки медленных сниппетов.
- **По умолчанию:** 50.

### modx3profilertoolbar.cli_enabled

- **Описание:** Профилировать ли запросы, выполняемые из CLI (например, кроны).
- **По умолчанию:** Нет.
- **Рекомендация:** Включайте только при отладке CLI-скриптов.

## Итоговая таблица настроек

| Ключ | По умолчанию | Описание |
|------|--------------|----------|
| modx3profilertoolbar.enabled | false | Включить профайлер |
| modx3profilertoolbar.sampling_rate | 100 | Процент запросов (1–100) |
| modx3profilertoolbar.frontend_toolbar | true | Показывать тулбар на фронте (только при входе в Manager) |
| modx3profilertoolbar.slow_query_ms | 100 | Порог медленного SQL (мс) |
| modx3profilertoolbar.slow_snippet_ms | 50 | Порог медленного сниппета (мс) |
| modx3profilertoolbar.cli_enabled | false | Профилировать CLI |
